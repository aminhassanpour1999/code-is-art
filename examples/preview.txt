# Default Code Is Art preview

The default command renders the phrase CODE IS ART using the compact 3x5 font:

```bash
python scripts/generate.py --preview
```

To preview another phrase:

```bash
python scripts/generate.py --text "HELLO WORLD" --font 3x5 --preview
```

For digits or punctuation, use the full 5x5 font:

```bash
python scripts/generate.py --text "A2026!" --font 5x5 --preview
```

This file documents the commands. The canonical glyph definitions are in
src/code_is_art/alphabet.py, and the renderer generates the live preview.
